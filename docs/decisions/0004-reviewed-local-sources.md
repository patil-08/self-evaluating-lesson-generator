# ADR 0004: Ground this focused topic in reviewed local sources

- **Status:** Accepted
- **Decision:** Maintain a small, human-reviewable source set for the Introduction to RAG lesson.
- **Reason:** The source basis can be inspected without external infrastructure, and a model's fluent answer is not treated as proof.
- **Trade-off:** The source set needs deliberate maintenance and is not a general-purpose knowledge base.
